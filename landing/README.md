# DClaw Waste — Landing Page

Marketing landing page for the DClaw Waste platform. Built with Next.js 14 (App Router) + Tailwind CSS, designed to deploy on Vercel.

## Sections

- **Hero** — animated gradient hero with headline, CTAs, and stats bar
- **Features** — 8 feature cards covering every platform module
- **How It Works** — 4-step onboarding walkthrough
- **ESG Section** — sustainability report showcase with mockup
- **Comparison** — competitive table vs Rubicon / RoadRunner / spreadsheets
- **Pricing** — 3-tier pricing (Starter / Professional / Enterprise)
- **CTA** — final call-to-action
- **Footer** — links and brand

## Develop

```bash
npm install
npm run dev      # http://localhost:3099
```

## Deploy

```bash
vercel           # preview
vercel --prod    # production
```

The `/login` and `/register` links point to the main app; update them to your deployed app URL.
